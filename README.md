# DCTI · 성경으로 알아보는 나의 교리 유형

DCTI(Doctrinal Conviction Type Indicator)는 16개 주제 40문항으로 교리 성향을 여섯 유형 가운데 하나로 보여 주는 정적 웹사이트입니다.

| 코드 | 별칭 | 유형 | 큰 틀 |
| --- | --- | --- | --- |
| BEREA | 베뢰아 상고자 | KJV 독립침례교형 | 근본주의 |
| COVNT | 언약의 건축가 | 개혁주의형 | 복음주의(보수) |
| UPPER | 다락방의 불꽃 | 오순절·은사주의형 | 복음주의 |
| ANTIO | 안디옥의 다리 | 주류 복음주의형 | 복음주의 |
| AREOP | 아레오바고의 탐구자 | 자유주의 신학형 | 자유주의 |
| TEMPL | 성전 뜰의 전례자 | 전례·전통교회형 | 전통교회 |

## 파일

- `js/data.js` — 문항, 보기, 유형 설명, 주제별 해설. 문장은 여기서만 고치면 됩니다.
- `js/scoring.js` — 채점과 결과 링크 인코딩
- `js/app.js`, `css/style.css`, `index.html` — 화면
- `test/types.test.js` — 각 유형의 모범 답안이 그 유형으로 나오는지 확인 (`node test/types.test.js`)

공유 링크(`?a=...`)는 문항마다 보기 번호 한 글자를 씁니다. 이미 퍼진 링크가 깨지지 않도록 보기 순서를 바꾸지 말고, 새 보기는 끝에 추가하세요.
